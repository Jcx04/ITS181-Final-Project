# ITS181-Final-Project

Course Project Description and Instructions

Create a Music Player desktop application using Java Programming Language.

The minimum requirements of the application are the following:

the user may choose a song title from the list (minimum of 5 titles)
once a song title was chosen, the music will play and the lyrics of the song will be displayed.
the user has the option to stop and pause the song currently playing
pictures relevant to the song may be shown 
NOTE: You may add more to this if you want to get higher grade.

Grade will be based on the following:

1. UI and UX Design (20 pts)

2. Application/Use of the following topics: (30 pts)

Layout Managers
Custom Event Handlers
MVC architecture
Persistence (JPA - not SpringBoot)
3. Complexity of the application (20 pts)

4. Uniqueness of the application (20 pts)

5. Demo/Presentation (10 pts)


Submit the link of the complete project file and video demo in Module 4.
